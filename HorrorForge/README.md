## Visual rule

UI and 3D assets are first-class project systems. Do not replace the HorrorForge visual language with generic Roblox UI templates or placeholder-looking panels/models.

Current P1 source package contains code, manifests, documentation and asset registries/specifications. Actual binary 3D/model/texture/audio assets are not fabricated where no source asset exists.
