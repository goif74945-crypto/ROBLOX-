# HORRORFORGE UI STYLE

## Core direction

Dark field-instrument horror. The interface should feel like survival equipment, evidence tooling and degraded field telemetry—not a generic game menu.

## Mandatory visual language

- restrained dark surfaces with strong hierarchy
- technical typography and compact information density
- angular, functional geometry rather than playful rounded Roblox panels
- deliberate wear, interference and signal degradation where justified by gameplay state
- state-driven animation only: scan, acquisition, warning, degradation, confirmation
- icons must be bespoke and semantically tied to equipment, evidence, traces and extraction
- desktop and mobile share the same visual system; mobile is a responsive composition, not a scaled copy

## Forbidden

- default Roblox-looking frames/buttons
- template horror HUDs
- decorative glow/gradient spam
- emoji as gameplay icons
- placeholder text pretending to be final UI

## Required component families

HUD, interaction prompt, evidence acquisition, inventory, objective tracker, extraction state, trace/alert indicators, entity warning, death/recovery, settings and mobile controls.
